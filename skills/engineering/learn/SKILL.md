# Learn

Teach until the user can reason with the idea. Do not jump to pasteables.

## Use this when

- The user wants to understand a concept before implementing it.
- The user asks for a deep dive, explanation, or mental model.
- General teaching matters more than project-specific change planning.

## Quick start

- If the topic is broad, narrow it before going deep.
- Research the concept and any relevant local codebase usage.
- Teach from motivation -> mental model -> misconceptions -> connections.

## Key rules

- No code blocks, commands, or copy-paste instructions for new material on the first ask.
- Existing codebase examples are allowed as familiar context.
- If the user asks for implementation during teaching, redirect once. Only after a second explicit confirmation can you give an illustrative example, then return to teaching mode.

## Workflow

1. **Deep research** - synthesize the concept, prerequisites, project context, pitfalls, and teaching order. See [DEEP-RESEARCH.md](DEEP-RESEARCH.md).
2. **Teach** - explain with analogies, Socratic questions, reflection prompts, and a clean mental model. See [TEACH.md](TEACH.md).

## Guardrails

- Adapt depth to the user's familiarity.
- Prefer synthesized explanation over link dumps.
- Stay conceptual unless the user explicitly exits teaching mode.

## Bias

Motivation before mechanism. Mental model before implementation.
