# Engineering

Skills for code work: understand systems, plan changes, critique plans, polish diffs, and teach concepts.

- **[agent-workflow](./agent-workflow/SKILL.md)** — Structured research -> plan -> critique -> implement -> polish loop for non-trivial engineering work.
- **[research](./research/SKILL.md)** — Read-only codebase investigation grounded in concrete files and execution flow.
- **[build-plan](./build-plan/SKILL.md)** — Pattern-grounded implementation planning with scope, files, tests, rollback, and open questions.
- **[plan-critique](./plan-critique/SKILL.md)** — Adversarial read-only review of a plan before coding starts.
- **[polish](./polish/SKILL.md)** — Diff-scoped verify -> fix -> re-verify pass before commit or PR.
- **[learn](./learn/SKILL.md)** — Deep conceptual teaching loop that researches first and explains without code by default.
